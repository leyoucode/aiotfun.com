技术博客一半的体验都在代码块上。这篇把站点支持的代码块能力一次列完，写文章时直接抄。

## 基础语法高亮

最常见的形态。fence 后面加语言标识就行。代码框右上 hover 出复制按钮。

```ts
type Status = 'active' | 'shipped' | 'paused';

function describe(status: Status) {
  switch (status) {
    case 'active': return '在做';
    case 'shipped': return '上线了';
    case 'paused': return '暂停';
  }
}
```

行内代码用反引号写，比如 `useState`、`pnpm build`、`ESP32-S3`，会带浅灰底等宽字体。

## 标题栏 / 文件名

加 `title="文件名"` 让代码块顶部显示文件名，强类型代码尤其好用。

```ts title="src/utils/articles.ts"
import { getCollection } from 'astro:content';

export async function getArticles() {
  const entries = await getCollection('articles');
  return entries.sort((a, b) =>
    new Date(b.data.date).getTime() - new Date(a.data.date).getTime()
  );
}
```

## 行号

加 `showLineNumbers` 显示行号。可以再加 `startLineNumber=` 改起始号。

```python showLineNumbers
def fib(n: int) -> int:
    if n < 2:
        return n
    a, b = 0, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

print(fib(10))  # 55
```

## 行高亮

用 `{1,3-5}` 圈出关键行 —— 调试笔记最常用。

```ts {2,5-7} title="重点看 retry 逻辑"
async function fetchWithRetry(url: string, retries = 3) {
  let lastErr: unknown;
  for (let i = 0; i < retries; i++) {
    try {
      const res = await fetch(url);
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      return await res.json();
    } catch (err) {
      lastErr = err;
      await new Promise((r) => setTimeout(r, 2 ** i * 100));
    }
  }
  throw lastErr;
}
```

## 插入 / 删除 行（diff）

不用 ` ```diff `，直接用 `ins={...}` 和 `del={...}` —— 优势是仍然走原语言的语法高亮。

```ts ins={4-5} del={3} title="重构前后对比"
function greet(name: string) {
  console.log('Hello, ' + name);
  return `Hi, ${name}`;
  console.log(`Hello, ${name}`);
  return `Hi, ${name}!`;
}
```

也可以用纯 `diff` 语言：

```diff
- "old line"
+ "new line"
  unchanged line
```

## 折叠

长代码块默认折一段，点击展开。中间无关的样板可以 `collapse={...}` 起来。

```ts collapse={1-6} title="重点在 main()"
import { defineConfig } from 'astro/config';
import tailwind from '@astrojs/tailwind';
import mdx from '@astrojs/mdx';
import sitemap from '@astrojs/sitemap';
import expressiveCode from 'astro-expressive-code';

function main() {
  return defineConfig({
    site: 'https://aiotfun.com',
    integrations: [tailwind(), expressiveCode(), mdx(), sitemap()],
  });
}

export default main();
```
